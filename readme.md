# pila
Implementacion de pila generica. Utiliza conceptos como:
- punteros genéricos (`void*` y `void**`)
- manejo dinámico de memoria con malloc, realloc, y free
- ampersand `&elem`

## archivos
- `pila.c`: implementacion
- `pruebas_pila.c`: uso

## uso
`gcc pila.c pruebas_pila.c testing.c -o pruebas_pila`
